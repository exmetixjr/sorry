# sorry 😭

A tiny Hinglish apology website made for one very unfortunate group-chat incident.

## Vibe
Goofy • hand-drawn • emotional • mobile-first • no backend

## Deploy
This is a static site and can be hosted directly with GitHub Pages.

## Note
The illustrations are CSS/emoji based for now, so the site does not depend on random hotlinked Pinterest images. External image assets can be added later if we find specific public/licensed ones that fit the vibe.
